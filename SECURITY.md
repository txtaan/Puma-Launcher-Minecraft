# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue:

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability** and describe the problem, how to reproduce it and what an attacker could do with it.

Only the maintainers can see the report. We'll reply as soon as we can, agree with you on when to publish the fix, and
credit you if you want.

Examples of what to report: a way to read or steal the Microsoft or Minecraft sign-in tokens the launcher stores, to make
it download or run files the user didn't ask for, or to run code through a crafted instance, mod, modpack or server
address.

## Supported versions

Fixes go into the [latest release](https://github.com/txtaan/Puma-Launcher-Minecraft/releases/latest). Please update
before reporting.
